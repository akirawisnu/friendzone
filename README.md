# Friendzone

A polished fictional dating app landing page with subtle jokes about being friendzoned.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site will be generated in `dist/`.

## Deploy

Upload the `dist/` folder to Netlify, Vercel, or GitHub Pages.
