# friendzone
Friendzone is a polished, semi-serious, fully unserious dating app landing page for people who are ready to be emotionally available, romantically rejected, and socially upgraded. Instead of promising soulmates, fireworks, or dramatic airport confessions, Friendzone guarantees something far more realistic: a friend. The site presents a fictional app where romantic chemistry is optional, friendship potential is dangerously high, and “long walks away from commitment” are considered a valid compatibility metric. Built as a responsive React/Vite project, it features professional app-style design, mock mobile screens, onboarding flows, trust sections, and subtle jokes about getting friendzoned while still making the product look like it could actually raise venture capital by accident.
